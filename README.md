# Tanks Blitz Cluster Switcher

Программа для macOS, которая блокирует кластеры Tanks Blitz через файл /etc/hosts. Удобно, если хочешь играть на конкретном сервере — остальные просто отключаются.

## Установка

1. Скачай приложение из раздела Releases
2. Перетащи в папку «Программы» или куда удобно
3. Запусти

При первом запуске macOS скорее всего скажет, что приложение от неизвестного разработчика. Чтобы запустить:
- Правый клик по приложению -> Открыть -> Открыть в окне предупреждения
- Если не сработало, пиши в телеграм @waffleeb

## Как пользоваться

1. Отметь галочками кластеры, которые хочешь заблокировать
2. Нажми «Применить»
3. macOS спросит пароль — это нормально, программа правит системный файл /etc/hosts
4. Перезапусти игру

Чтобы разблокировать всё — сними все галочки и нажми «Применить».

### Важно

- Нельзя заблокировать все кластеры сразу — игра просто не запустится. Программа не даст это сделать, но всё равно не пытайся.
- После блокировки нажми «Обновить статус», чтобы увидеть что сейчас заблокировано.
- Кнопка «Восстановить hosts» откатывает файл к состоянию до последней блокировки. Полезно, если что-то сломалось.

## Функции

- Два языка — русский и английский (выбор запоминается между запусками)
- Защита от дурака — не даст заблокировать все сервера разом
- Проверка обновлений через GitHub
- Восстановление hosts из резервной копии в один клик
- История последних действий
- Системный трей

## Частые вопросы

**Зачем пароль?**
Программа пишет в /etc/hosts, а это системный файл. Без прав админа никак.

**Всё сломалось, что делать?**
Нажми «Восстановить hosts». Если не помогает — открой /etc/hosts вручную и удали строки с 127.0.0.1 login.

**Безопасно ли это?**
Да. Программа только добавляет и удаляет строки в /etc/hosts и чистит DNS-кэш. Перед каждым изменением создаётся резервная копия.
